# GoodNotesRestoreApp Skeleton

이 폴더는 iPad 앱에서 필요한 SwiftUI 소스 골격이다. 현재 앱 소스는 `GoodNotesRestoreApp/` 하위 폴더에 위치한다.

```text
GoodNotesRestoreApp/GoodNotesRestoreApp.swift
GoodNotesRestoreApp/ContentView.swift
GoodNotesRestoreApp/APIClient.swift
GoodNotesRestoreApp/Models.swift
GoodNotesRestoreApp/PasteboardWriter.swift
```

실제 iPad에서 Mac의 로컬 서버에 접근하려면 `127.0.0.1` 대신 Mac의 LAN IP 주소를 사용해야 한다.
